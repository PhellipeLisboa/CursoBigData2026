
# Análise dos Mundiais de League of Legends
 
Projeto de análise exploratória dos dados dos Campeonatos Mundiais de
League of Legends entre 2011 e 2022.
 
## Objetivo
 
Praticar Python, Pandas e NumPy por meio da inspeção, limpeza,
transformação e análise de dados relacionados a jogadores, campeões
e partidas dos Mundiais.

## Fonte dos dados

Os dados foram obtidos no Kaggle: [League of Legends Worlds (2011-2022) Stats](https://www.kaggle.com/datasets/pedrocsar/league-of-legends-worlds-20112022-stats)

Autor: Pedro César
 

Arquivos utilizados:
 
- `players_stats.csv`
- `champions_stats.csv`
- `matchs_stats.csv`
