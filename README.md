# CursoBigData2026

Este repositório contém materiais produzidos durante o curso de **Analista de Dados - Big Data Science** do **SENAC**. 

Aqui estão organizadas as anotações de aula, códigos desenvolvidos em sala, resoluções de exercícios e materiais de estudo complementar produzidos ao longo da formação.

## Estrutura do repositório

```
.
├── UC1/
│   ├── anotacoes/
│   ├── aula01/
│   ├── aula02/
│   ├── ...
│   ├── exercicios/   
│   └── projeto/
└── estudos-complementares/
    └── python/
```

### UC1/ 
Contém os materiais referentes à Unidade Curricular 1.

### UC1/anotacoes/ 
Armazena minhas anotações de aula em arquivos de texto.

**Nomenclatura dos arquivos** : notas-aula-ddMMyyyy.txt

### UC1/aulaXX/ 
Diretórios criados para armazenar scripts desenvolvidos durante as explicações e demonstrações realizadas pelo professor em cada aula.

**Nomenclatura dos arquivos** : aulaXX-ddMMyyyy.py

### UC1/exercicios/
Armazena as soluções dos exercícios propostos nas aulas. Cada aula possui seu próprio diretório:

```
exercicios/
├── aula01/
├── aula02/
└── aula03/
```

**Nomenclatura dos arquivos** : nome-do-exercicio.py

**Observação 01** : Nos exercícios da aula 01, quando não havia decidido o padrão atual de organização, foram criados subdiretórios contendo tanto os scripts dos exercícios quanto versões em texto descrevendo passo a passo os algoritmos utilizados.

**Observação 02** : O diretório materiais-complementares foge do padrão de nomenclatura por não ser exercícios de alguma aula específica, mas armazena exercícios oficiais do curso que abrangem diversos assuntos abordados na UC1.

### UC1/exercicios/
Diretório que armazena a função listar_pedidos_da_mesa() (e o arquivo que utilizei testá-la) desenvolvida para integrar ao projeto final do módulo 1 (CASO: Restaurante Japonês Tanoshimi). 

### estudos-complementares/
Diretório destinado aos estudos realizados além do conteúdo oficialmente abordado no curso.

O objetivo é aprofundar conhecimentos relacionados à programação, análise de dados e demais temas relevantes para a formação profissional.

Os materiais são organizados por assunto e podem incluir:

- Conceitos teóricos
- Resumos e anotações
- Exemplos de código
- Estudos de sintaxe Python
- Listas de exercícios geradas por IA
- Resoluções de exercícios
- Experimentos
- Projetos pessoais

```
estudos-complementares/
└── python/
```
